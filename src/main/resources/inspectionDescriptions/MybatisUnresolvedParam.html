Reports parameter names in MyBatis mapper XML files that do not match any binding available to the statement: #{...} / ${...} expressions, test attributes of <if>/<when> tags and collection attributes of <foreach> tags are checked against the mapper method's @Param names, parameter names, bean properties and enclosing <foreach> item/index variables. Statements whose bindings cannot be statically determined (e.g. a single Map parameter or an unresolvable mapper method) are not reported.
